# 🎹 PIANO PRO — by Tama-ID

PIANO PRO adalah piano virtual berbasis HTML, CSS, dan JavaScript yang dapat dimainkan langsung melalui browser.

## ✨ FITUR

- 🎹 Piano manual dengan nada sesuai tuts.
- 🎵 Auto Play untuk memainkan lagu otomatis.
- 🔥 Hybrid Mode: main piano manual sambil lagu otomatis berjalan.
- ⏸️ Pause dan Resume.
- ⏹️ Stop dan reset lagu.
- 🎼 Berbagai pilihan lagu.
- 🎧 Bass Passacaglia otomatis.
- ✨ Animasi tuts piano.
- 📱 Tampilan responsif untuk HP dan desktop.
- 🖼️ Logo Tama-ID pada bagian header.

## 📁 STRUKTUR FILE

```text
PIANO-PRO/
├── index.html
├── logo.jpg
└── README.md
```

**Penting:** File logo harus bernama tepat `logo.jpg` dan berada satu folder dengan `index.html`.

## 🚀 CARA MENJALANKAN

1. Download atau clone repository.
2. Pastikan `index.html` dan `logo.jpg` berada dalam folder yang sama.
3. Buka `index.html` menggunakan browser.
4. Tekan PLAY atau pilih lagu untuk memulai.

## 🎮 CARA MENGGUNAKAN

| Tombol | Fungsi |
|---|---|
| PLAY | Memulai lagu otomatis |
| PAUSE | Menjeda lagu |
| RESUME | Melanjutkan lagu |
| STOP | Menghentikan dan reset lagu |
| MENU LAGU | Memilih lagu |
| TUTS PIANO | Memainkan nada secara manual |

## 🌐 AKTIFKAN GITHUB PAGES

1. Upload semua file ke repository GitHub.
2. Buka Settings.
3. Pilih Pages.
4. Pilih Deploy from a branch.
5. Pilih branch main dan folder /(root).
6. Klik Save.
7. Tunggu proses deployment selesai.
